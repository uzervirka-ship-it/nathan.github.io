Connecter ma banque

Connexion automatique à Revolut via Enable Banking (gratuit pour tes propres comptes, sans SIRET, standard officiel PSD2). Config une fois, puis resynchro en 1 clic.

Alternative : importer un relevé Revolut

Marche toujours, même sans rien configurer.

Dans l'app Revolut : Compte → ⋯ → Relevé → format Excel ou CSV → période. Dépose le fichier ici. Il est lu dans ton navigateur, rien n'est envoyé ailleurs, et les doublons sont ignorés. Les entrées d'argent (salaire, virements reçus) sont aussi reprises.
